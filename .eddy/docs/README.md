# Eddy documentation

The source of the Eddy documentation site, built with [Docusaurus](https://docusaurus.io/). The pages live in `content/`.

```bash
npm install     # Install the dependencies
npm start       # Serve the site locally, reloading on every change
npm run build   # Build the static site into build/
npm test        # Run the component tests and the spell check
```

See [Documentation](content/contributing/documentation.mdx) for how the site is built, checked and published.
